## Resumo — Propriedades de uma transformação linear

Se `T: V → W` é linear:

1. `T(0) = 0` (o vetor nulo é preservado).
2. `T(−v) = −T(v)`.
3. `T(α₁v₁ + α₂v₂ + … + αₖvₖ) = α₁T(v₁) + … + αₖT(vₖ)` (combinações lineares são preservadas).
4. Se `{v₁,…,vₙ}` é uma base de V, `T` fica **completamente determinada** pelos valores `T(v₁),…,T(vₙ)`.
5. `T` é **injetora** ⇔ `N(T) = {0}`; é **sobrejetora** (em W de mesma dimensão) ⇔ `Im(T) = W`.
6. Matriz associada: `[T(v₁) … T(vₙ)] = A·[v₁ … vₙ]` — composição de transformações ≡ **produto de matrizes**.
